# SIES_IP_CFT_U v1.2.0

Versión portable del informe Power BI de matrícula SIES para IP, CFT y universidades.

## Novedades

- Separación de Plan Regular, Plan Especial y Plan Regular de Continuidad conforme a las definiciones oficiales de SIES.
- Plan Especial deja de formar parte de un macrogrupo de Continuidad y se presenta con sus propias matrículas total y de primer año.
- Plan Regular de Continuidad se presenta solo con matrícula total; SIES no lo considera posible de contar con estudiantes de primer año.
- Rankings, participaciones, variaciones y segmentos competitivos pasan a utilizar primer año de Plan Regular.
- Advertencia explícita de que el tipo de plan es autorreportado por cada institución y no es reinterpretado por este informe.

## Cambios en la comparación competitiva

- `Otros competidores`: umbral de 900 matrículas regulares de primer año en la base fija 2026.
- `U (otras)`: umbral de 70 matrículas regulares de primer año en la base fija 2026.
- Las cifras de primer año SIES se conservan como referencia metodológica y corresponden a Plan Regular más Plan Especial.

## Descarga recomendada

Descargue `SIES_IP_CFT_U_v1.2.0.pbix` para abrir y explorar el informe directamente en Power BI Desktop. El archivo incluye los datos públicos agregados 2023–2026 ya importados.

El código fuente PBIP permanece disponible en el repositorio para auditoría, desarrollo y actualización de los CSV.
