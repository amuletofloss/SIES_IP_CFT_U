# SIES_IP_CFT_U v1.0.0

Primera versión pública del informe Power BI de matrícula SIES para IP, CFT y universidades.

## Contenido

- Diez páginas analíticas.
- Periodo 2023–2026.
- Filtros por año, modalidad, jornada, grupo y subgrupo de plan.
- Análisis IP+CFT, universitario, continuidad, áreas y competencia.
- Vista institucional ECS basada exclusivamente en datos SIES.

## Descarga recomendada

Adjunte `SIES_IP_CFT_U_v1.0.0.pbix` como activo de esta Release. El PBIX está destinado a usuarios que solo necesitan abrir y explorar el informe. El código fuente PBIP permanece en el repositorio.

## Integridad

Antes de publicar, registre en estas notas el tamaño y SHA-256 del PBIX generado.
